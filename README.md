# LifeLine — Digital Blood Donor & Emergency Help Network

A campus-based emergency platform connecting verified student blood donors with people who need blood urgently.

**Problem statement:** In medical emergencies, finding a suitable blood donor quickly is critical. LifeLine connects donors in college campuses based on blood group and availability, with emergency request features, to save lives.

## Features

- Emergency blood request with urgency levels
- Verified donor directory filtered by blood group
- Interactive blood compatibility tool (all 8 groups)
- Live donor availability indicators
- Fully responsive design (mobile, tablet, desktop)
- Real-time pulse animations and counters

## Tech

Single-file static site — pure HTML, CSS, JavaScript. No build step. No dependencies. Open `index.html` in any browser.

## Run Locally

Just double-click `index.html`.
